# Blog Category Classification using Naive Bayes and Sentiment Analysis

## Project Overview

This project performs blog category classification using the Naive Bayes algorithm and sentiment analysis using TextBlob. The dataset contains blog posts and their corresponding categories.

## Dataset

The dataset contains the following columns:

- **Data** : Blog post content
- **Labels** : Category of the blog

## Technologies Used

- Python
- Pandas
- Scikit-learn
- NLTK
- TextBlob
- Matplotlib
- Seaborn

- Data Loading
- Data Exploration

- Model Evaluation
